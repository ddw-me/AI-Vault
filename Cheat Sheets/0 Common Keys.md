# Common Obsidian Commands

Keyboard shortcuts vary by operating system and personal configuration. Use Obsidian's **Settings → Hotkeys** to see or change the shortcuts on your device. The command names are more portable than shortcut keys.

## Useful built-in commands

- **Open today's daily note** — open or create the note for the current date.
- **Create new note** — create a blank note in the current vault.
- **Insert template** — insert a configured note template at the cursor.
- **Open command palette** — search for any Obsidian command by name.
- **Search current vault** — find text across notes.
- **Quick switcher** — find and open a note by name.
- **Open graph view** — explore links and notes visually, if useful.

## Useful setup locations

- **Settings → Core plugins** — enable Daily notes and Templates.
- **Settings → Files and links** — choose attachment and link behavior.
- **Settings → Hotkeys** — inspect shortcuts for the current device.
- **Settings → Community plugins** — review optional plugins before enabling them.
