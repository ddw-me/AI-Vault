# Provenance and Sharing Checklist

This vault was adapted from Mark Bakke's `mbakke-ai-notes-workflow` repository. The initial seed came from commit `434cf7b`, as recorded in [VARIATION](./VARIATION.md). The result is a portable adaptation, not an unmodified copy.

Before publishing or redistributing an archive:

- confirm the source repository's permission or license for the material being adapted;
- provide any attribution required by that permission or license;
- remove personal, company-specific, credential, and private note content;
- review the branch's `VARIATION.md` and the committed file list;
- verify the archive can be opened as an Obsidian vault.

This checklist intentionally does not assert a license that has not been verified.
