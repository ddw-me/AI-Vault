## 🔧 Recommended Cursor Configuration

**For optimal AI assistance:**

1. **Use Agent Mode** - Switch to "Agent" mode in Cursor's chat interface for more powerful, action-oriented assistance
2. **Model Selection** - Claude-4-Sonnet has proven highly effective for this workflow (if available in your Cursor setup)
3. **Workspace Context** - Keep this file (`cursor.md`) open to provide the AI with workflow context

**Why Agent Mode?** Agent mode allows Cursor to take actions (create files, run commands, edit multiple files) rather than just providing suggestions, making it ideal for workflow automation and daily note management.

## Daily Workflow

### Morning Startup
Start each day by asking Cursor:
```
Good morning, today is [Date]. Could you roll the daily notes as usual?
```

Cursor will:
- Create your new daily note using the template
- Review yesterday's incomplete tasks and carry them forward
- Set up your structured planning template
- Suggest priority ranking based on task persistence

### Key AI Collaboration Patterns

**Daily Planning:**
```
Help me plan my day. Review my priorities and suggest optimal sequencing based on my energy patterns and calendar.
```

**Meeting Summarization:**
```
Could you summarize our [meeting type] from today's notes in a manner suitable for sharing with the wider [audience] team?
```

**Weekly Review:**
```
Please analyze this week's daily notes and create a weekly summary focusing on:
- Key accomplishments and strategic progress
- Patterns in productivity and energy
- Persistent tasks that need escalation
- Opportunities for process improvement
```

**Project Creation:**
```
I need to create a new project called "[Project Name]". Please:
1. Create a new file in the "Active Projects" folder using the Project Template
2. Set up the project structure with proper sections
3. Help me break it down into actionable steps with realistic timelines
```

**Project Management:**
```
Help me break down [project name] into actionable steps with realistic timelines based on my typical work patterns.
```

## Agent Framework

Work with specialized virtual agents for different responsibilities:

- **Historian**: Track activities, generate summaries, identify patterns
- **Curator**: Organize notes, maintain cross-references, suggest improvements
- **Scheduler**: Optimize timing, batch tasks, protect deep work
- **Operations**: System health, friction identification, process improvement

Ask agents directly:
```
Historian: What patterns predict my best work days?
Curator: How should I organize these project notes?
Scheduler: What's the optimal sequence for today's tasks?
Operations: What friction points can we eliminate?
```
